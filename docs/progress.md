| 内容 | 掌握程度 |
|---|---|
| **三要素**：`data_` 指针 / `size_` 个数 / `capacity_` 容量 | ✅ |
| **扩容策略**：容量翻倍、`new T[n]` 分配、复制、`delete[]` | ✅ |

### D3 新增：链表

| 内容 | 掌握程度 |
|---|---|
| **节点结构**：`struct Node { int value; Node *next; }` 自引用 | ✅ |
| **嵌套类型**：`Node` 写在 `class` 私有区 | ✅ |
| **遍历两种条件**：`cur != nullptr`（全部）/ `cur->next != nullptr`（停在尾巴） | ✅ |
| **头插 O(1)**：`new Node{v, head_}; head_ = new_node;` | ✅ |
| **头删顺序**：先存 `old`，再移 `head_`，最后 `delete` | ✅ |
| **`remove` 连删**：删除后**不能**前进 | ✅ **一次写对** |
| **头节点特殊处理**：`while` 循环处理连续匹配 | ✅ |
| **`tail_` 优化**：`push_back` 从 O(n) 到 O(1)，代价是每个操作多检查 | ✅ |
| **三指针同步**：`head_` / `tail_` / `size_` 必须始终一致 | ✅ 六组测试通过 |

### D3+ 新增：双链表

| 内容 | 掌握程度 |
|---|---|
| **`prev` 指针**：`struct Node { int value; Node *next; Node *prev; }` | ✅ |
| **不变式**：`A->next == B` 则必须 `B->prev == A` | ✅ |
| **`push_back` 双指针**：`{value, nullptr, tail_}` + 改 `tail_->next` | ✅ |
| **`push_front` 对称**：`{value, head_, nullptr}` + 改 `head_->prev` | ✅ |
| **`pop_back` O(1)**：`tail_ = tail_->prev`，不用遍历 | ✅ **解决了单链表的遗留问题** |
| **删除时维护 prev**：删中间要接 `old->next->prev = cur` | ✅ |
| **当场维护 vs 事后补偿**：`tail_ = cur` 代替重新扫尾 | ✅ **学生自己提出的优化** |
| **四指针同步**：`head_` / `tail_` / `size_` / 各节点 `prev` | ✅ 八组测试通过 |

## 易错点

### 继承自主课表

| 错误 | 说明 | 提醒时机 |
|---|---|---|
| `=` 当 `==` | 写任何 `if` 时 | 写条件判断时 |
| 拼写错误 | 报"未声明"时先查拼写 | 编译报错时 |
| 依赖传递性包含 | 该 `#include` 的必须自己写 | 用新容器时 |
| 改一半就交回 | 交作业前把问题清单逐条打勾 | 提交前 |
| 该调的成员函数没调 | 用近似表达式代替 | 设计接口时 |
| 类外函数写在 `.h` 里没加 `inline` | 多文件会重复定义 | 写头文件时 |
| 状态忘记重置 | 临时状态在操作结束时要恢复 | 写状态机时 |

### D1 新增

| 错误 | 说明 | 提醒时机 |
|---|---|---|
| **复杂度不化简** | 写 `O(10n)`、`O(log₃n)`、`O(n/2)` 而非 `O(n)`、`O(log n)`、`O(n)` | 写任何复杂度结论时 |
| **求和式写成乘积** | 三角循环写成 `n*(n-i)`，但 `i` 在变动 | 遇到内层依赖外层的循环时 |

### D2 / D3 新增

| 错误 | 说明 | 提醒时机 |
|---|---|---|
| **`delete` 配 `new[]`** | 必须 `delete[]`，否则未定义行为 | 写析构时 |
| **模板类定义在类外** | 要写 `template<typename T>` + `MyVector<T>::` | 写模板类实现时 |
| **`new_data` 拼成 `new_date`** | 不影响编译，但误导 | 命名时 |
| **链表的 `->` 和 `.`** | `cur` 是指针用 `->`，`Node` 对象用 `.` | 写节点访问时 |
| **删除后仍前进** | `remove` 里删完再 `cur = cur->next` 会漏删连续值 | 写删除类操作时 |
| **`tail_` 忘了维护** | `push_front` 空链表、`pop_front` 删空、`remove` 删尾都要修 | 加 `tail_`/`prev_` 等辅助指针时 |

### 概念理解（提问记录）

| 误解 | 正确理解 |
|---|---|
| 「`&other = a`」 | `&other` 是**地址**，等于 `&a`，不是等于 `a`（值） |
| 「引用是一个变量」 | **引用是别名，不是变量**，没有独立地址、不占内存 |
| 「`grow()` 不需要深拷贝是因为指针没析构函数」 | 更准确：**`new_data` 是局部指针，切换后只有 `data_` 一个责任者** |
