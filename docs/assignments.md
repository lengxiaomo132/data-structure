## 数据结构课特有的检查项

**每次作业都要检查：**

| 检查项 | 说明 |
|---|---|
| **手写实现** | 不许调用 `std::xxx` |
| **自己写的测试** | 至少覆盖：空、单元素、多元素、边界 |
| **复杂度注释** | 在函数上方写 `// O(n) time, O(1) space` |
| **不泄漏内存** | 用 `new` 就要有对应的 `delete`，或直接用 `unique_ptr` |
| **零 UB** | 不越界、不解引用空指针、迭代器不失效 |
| **零警告** | `-Wall -Wextra` |
