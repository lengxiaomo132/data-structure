# 第一阶段：数据结构（D1–D12）

## 课程表

| 课次 | 主题 | 必须理解 / 验收标准 | 产出 | Gameplay 关联 |
|---|---|---|---|---|
| **D1** | 复杂度、内存布局、缓存局部性 | 能估算时间/空间复杂度；解释连续内存、缓存局部性；用实验比较访问方式，避免把某个实验倍数当普遍规律 | benchmark 报告 | 每帧遍历对象、数据布局与性能 |
| **D2** | 数组与动态数组 | 手写 `MyVector`：`push_back`、`pop_back`、`[]`、`resize`；解释容量、扩容、均摊复杂度 | `my_vector.h` | 对象列表、连续存储、批量遍历 |
| **D3** | 链表 | 手写单向/双向链表；掌握插入、删除、查找；能比较 `vector` 与 `list` 的真实使用场景 | `my_list.h` | 认识节点结构；理解为何游戏代码通常更重视连续内存 |
| **D4** | 栈、队列、双端队列 | 手写栈、队列；了解循环数组队列；**会使用 `std::deque` 的四个操作（`push_front`/`push_back`/`pop_front`/`pop_back`），知道它和 `vector` 在头部插入上的差别**；能解释 FIFO/LIFO | `my_stack.h` / `my_queue.h` | 消息缓冲、任务处理、撤销/回溯 |
| **D5** | 哈希表 | 手写一种实现（开放寻址或链地址法）；理解 hash、冲突、负载因子、扩容；知道另一种方案的差异 | `my_hashmap.h` | Entity ID 查找、缓存、状态映射 |
| **D6** | 递归、二叉树与遍历 | 手写节点与前序/中序/后序、层序遍历；理解递归栈；能把递归改为迭代（至少一个例子） | `binary_tree.h` | 层级数据、行为/状态结构的基础概念 |
| **D7** | 二叉搜索树（BST） | 手写插入、查找、删除；解释平均与最坏复杂度；知道不平衡会退化 | `bst.h` | 理解有序查询结构，不要求游戏中常用 BST |
| **D8** | 堆与优先队列 | 手写最小堆/最大堆的核心操作；掌握 `priority_queue` 与 comparator | `my_heap.h` | 事件/任务优先级、最早时间事件 |
| **D9** | 图与 BFS / DFS | 邻接表；手写 BFS/DFS；理解 visited；会用 BFS 求无权图最短路 | `graph.h` | 地图、关卡连接、基础寻路概念 |
| **D10** | 并查集 | 手写 union-find，含路径压缩与按秩/大小合并；能分析近似效率 | `union_find.h` | 连通区域、岛屿/区域合并等问题 |
| **D11** | 空间划分：Grid | 实现二维网格；把对象映射到 cell；查询附近对象；处理 cell 边界与对象移动 | `spatial_grid.h` | 高频重点：附近敌人、碰撞候选、AOI 基础 |
| **D12** | 项目：Enemy Manager | 线性遍历 vs Grid；正确性一致；N=100/1000/10000 测试；报告不同分布下的结果与限制 | `enemy_manager/` | 将数据结构转化为实际 Gameplay 问题 |

### 数据结构里程碑

- **D2 后**：理解连续存储、动态扩容；能使用并简单实现动态数组。
- **D5 后**：能在数组、链表、栈、队列、哈希表之间按操作需求选择。
- **D8 后**：能处理树、优先级和递归类问题。
- **D9 后**：能写基础图遍历，理解无权图 BFS 最短路径。
- **D12 后**：能用实验说明空间划分是否值得，以及它的适用条件。

### 产出物验收标准

**D1 benchmark 报告**

- 至少对比 **3 组** 访问方式（例如：`vector` 顺序遍历 / `list` 顺序遍历 / `vector` 随机访问）
- 每组跑 **5 次取平均**
- 报告测试条件：编译选项、元素数量、运行环境
- **结论要写「这说明什么」**，不只是贴数字
- **注意**：单次测量的倍数不能直接当成普遍规律，要说明测试条件的影响

**D12 Enemy Manager 报告**

- 三种规模 N（100 / 1000 / 10000）× 两种实现（线性遍历 / Grid）
- **正确性**：两种方法的查询结果必须一致（同一查询，返回同一批对象）
- **性能**：给出耗时对比表
- **分布**：至少测试两种对象分布（均匀 / 聚集）
- **结论**：什么情况下 Grid 有收益，什么情况下维护成本超过收益

# 第二阶段：基础算法（A1–A7）

与 D 课程并行：每学到一个主题就做练习，不需要等 D12 全部结束。

**A 系列的依赖关系**：

| 课次 | 依赖 |
|---|---|
| **A1–A3、A5–A7** | **不依赖任何 D 课**，可以随时开始 |
| **A4（排序）** | 其中的**堆排序**部分依赖 **D8**；快速排序、归并排序不依赖 D 课 |

| 课次 | 主题 | 必须掌握 | 练习方向 |
|---|---|---|---|
| **A1** | 二分查找 | 标准二分；边界；`lower_bound` / `upper_bound`；循环不变量；能判断何时可二分 | 搜索插入位置、查找范围 |
| **A2** | 双指针 | 左右指针、快慢指针；理解适用条件 | 有序数组、移除元素、链表中点 |
| **A3** | 滑动窗口 | 窗口扩张/收缩；维护窗口状态 | 最长无重复子串、最小覆盖类入门 |
| **A4** | 排序 | 插入排序原理；快速排序/归并排序思路；复杂度与稳定性；熟练使用 `std::sort` 和 comparator | 排序对象、按多个字段排序 |
| **A5** | 递归与回溯 | 递归树、终止条件、状态恢复；能写组合/排列/简单搜索 | 组合、排列、迷宫搜索 |
| **A6** | 基础动态规划 | 状态、转移、初始条件；从暴力递归到 DP；先掌握 1D DP | 爬楼梯、打家劫舍、简单背包理解 |
| **A7** | 位运算与字符串基础 | `&`、`\|`、`^`、`~`、移位；bitmask；字符串遍历、频次统计、回文 | 位标记、状态集合、字符计数 |

### 算法练习原则

- 每个主题至少 **3 道题**：一道基础、一到两道变式。
- 不以"看懂答案"为完成；先独立写，卡住后再看提示。
- 题目做完要写：关键思路、复杂度、边界条件、为什么其他方法更差。
- 初期不要追求刷题数量；优先能复述思路并独立重写。

# 面试准备：必须能说清楚的题型

## 数据结构与算法

- `vector` 与 `list` 的差别，为什么连续内存常常更快？
- 哈希表如何解决冲突？负载因子是什么？
- 栈与队列分别适合什么问题？
- BST 为什么可能退化？如何改善？
- 堆为什么适合 Top K / 优先级任务？
- BFS 与 DFS 的差别；BFS 为什么能求无权图最短路？
- 二分查找的边界为什么容易错？
- 时间复杂度如何从循环/递归推导？
- 如何用 Grid 减少附近对象查询？它有哪些限制？

## C++ 基础（已有课程，不重复系统讲）

- `const`、引用、指针、对象生命周期
- 拷贝与移动；`unique_ptr` 的所有权
- 虚函数、多态、虚析构
- STL 常用容器与迭代器
- Lambda、Comparator
- RAII、未定义行为、常见内存错误
- 编译、链接、多文件工程

**要求**：复习与练习，不新增一整套 C++ 课程。

# 每课结构

| 阶段 | 时长参考 | 内容 |
|---|---|---|
| 讲解 | 30–40 分钟 | 为什么需要 + 原理 + 最小可运行例子 |
| 演示 | 15 分钟 | 故意写错的实现，观察问题 |
| **你写** | 60–90 分钟 | 手写实现 / 算法练习 |
| 批改 | 20 分钟 | 正确性 + 复杂度 + 边界 + 代码质量 |

每个数据结构/算法都要求：

1. **解决什么问题？**
2. **不用它会怎样？** 尽量用操作次数或实验说明。
3. **什么时候不适合用？**
4. **时间与空间复杂度怎么算出来？**
5. **正常、边界、异常测试。**
6. **能独立复述并重写核心代码。**
